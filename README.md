# LASA Landing

Proyecto de rediseño de la landing institucional y comercial de **LASA Papelera**.

## Objetivo
Desarrollar una nueva landing que represente mejor a la empresa, su trayectoria, su actividad y su perfil comercial, con una estructura más clara, una identidad más sólida y una mejor experiencia visual.

## Estructura del proyecto

- `01-brief/`  
  Documentación general del proyecto y definición estratégica.

- `02-contenido/`  
  Textos base y contenido inicial para la nueva landing.

- `03-referencias/`  
  Criterio visual, referencias y lineamientos de diseño.

- `04-diseno/`  
  Material vinculado al proceso de diseño.

- `05-web/`  
  Primera versión de la landing en HTML, CSS y JavaScript.

## Estado actual
Proyecto en etapa inicial de definición, estructura y primera base visual.
